# Array Rotation and Reversal

This folder focuses on rotating arrays and reversing array elements using in-place operations.

## What you will learn
- Left rotation by one position
- Left rotation by multiple positions
- Reversing arrays using swap logic
- Rotating arrays using the reverse-in-three-steps approach
- Moving zeros to the end while preserving order
- Rearranging positives and negatives in a custom pattern

## Files
- leftrotatebyone.cpp - shifts elements one step to the left
- leftrotateby3.cpp - rotates the array by three positions
- leetcode189.cpp - classic array rotation problem solution
- reverseArray.cpp - reverses an array using swap pointers
- reverloop.cpp - simple reverse traversal example
- movezeros.cpp - moves all zeros to the end
- movezeroscpp.cpp - another variation using a set-based approach
- rearrangeelement.cpp - rearranges positive and negative values

## Study tip
Rotation problems become much easier when you think in terms of reversing subarrays.
