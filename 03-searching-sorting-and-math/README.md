# Searching, Sorting, and Math Patterns

This folder covers foundational search and sort problems along with simple math-based tricks.

## What you will learn
- Linear search for target values
- Checking whether an array is sorted
- Sorting ideas and counting-based patterns
- Two-pointer style sum finding
- Next permutation logic
- Basic number-based problem solving

## Files
- linearsearch.cpp - demonstrates linear search
- sortarray.cpp - explores sorting ideas
- sortedArray.cpp - checks whether an array is sorted
- sortedArrayOrnot.cpp - another sorted-check style example
- sumoftwovalue.cpp - finds two values whose sum matches a target
- nextpermutation.cpp - builds the next lexicographical permutation

## Study tip
For these problems, always try to identify whether the solution is brute force, optimized, or based on a clever observation.
