# Array Basics

This folder contains beginner-level problems around arrays, maxima, minima, and frequency-based thinking.

## What you will learn
- How to find the maximum and minimum values in an array
- How to spot the second largest element
- How to detect a missing number using arithmetic sum
- How to identify the majority element conceptually
- How to explore subarray patterns and maximum values

## Files
- largest.cpp - finds the largest element in an array
- largest2.cpp - another simple maximum-finding implementation
- largestconsecutiveones.cpp - demonstrates bitwise XOR-based thinking for paired values
- majorityElement.cpp - explores the Boyer-Moore majority vote idea
- maxofsunarray.cpp - brute-force approach to maximum subarray sum
- missingnumber.cpp - finds the missing value using sum formula
- secondLargest.cpp - finds the second largest element
- smallestNumber.cpp - finds the smallest element in an array

## Study tip
Always try to solve each problem in two ways: first with a brute-force idea, then with a more optimized one.
