# Vectors and STL Basics

This folder is for understanding C++ vectors, pairs, and basic Standard Template Library usage.

## What you will learn
- How vectors work in C++
- Iterating over vectors
- Using pairs to store two values together
- Passing arrays and vectors through functions
- Basic STL concepts such as sets and maps

## Files
- vectors.cpp - basic vector usage
- vectoritrator.cpp - iterating through a vector
- pairs.CPP - demonstrates pair containers
- passBYvalue.cpp - shows pass-by-value and array behavior

## Study tip
If you are new to C++, spend extra time understanding vectors and pairs because they appear in most competitive programming solutions.
