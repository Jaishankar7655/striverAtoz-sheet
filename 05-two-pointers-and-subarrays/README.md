# Two Pointers and Subarray Problems

This folder contains problems that focus on scanning arrays with two pointers and analyzing subarrays.

## What you will learn
- Two-pointer traversal patterns
- Union-style array problems
- Kadane's algorithm for maximum subarray sum
- Leader element problems in an array

## Files
- 2pointerunion.cpp - explores a two-pointer style union approach
- kadanesAlgo.cpp - implementation of Kadane's algorithm
- leader.cpp - finds leader elements in an array

## Study tip
Two-pointer problems usually become simple once you identify the left-right movement pattern clearly.
